# Tally: habit tracker

Tap a circle to mark a habit done today. Tap the small day squares to fix past days. Data stays on your phone (back up from the app).

## Install as an app (easiest)
1. Create a GitHub repo and push these files to `main`.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. After the "Deploy web app" action finishes, open `https://<your-username>.github.io/<repo-name>/` in Chrome on your phone.
4. Tap the **Install app** button (or Chrome menu > Add to Home screen).

## Get an APK
Repo > Actions > **Build APK** > Run workflow. When it finishes, download the `tally-apk` artifact, unzip it, and open `app-debug.apk` on your phone (allow "install unknown apps").
